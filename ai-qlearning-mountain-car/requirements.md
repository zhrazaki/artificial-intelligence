# Environment & Dependencies — ai-qlearning-mountain-car

Python-kernel notebook. No `requirements.txt` is committed; the environment
is documented here.

## Runtime

- **Python** ≥ 3.10 (developed on Google Colab)
- Jupyter Notebook / Google Colab

## Python Packages

| Package | Used for | Install |
|---|---|---|
| `gymnasium` | the `MountainCar-v0` environment | `pip install gymnasium` |
| `numpy` | Q-table, discretization | `pip install numpy` |
| `matplotlib` | reward/ε plots, 3D value surface | `pip install matplotlib` |
| `pygame` | only for the optional `render_mode="human"` cell | `pip install pygame` |

## Data

No external datasets; everything is generated by interacting with the
gymnasium environment.

## Reproducibility Notes

- Training is stochastic (ε-greedy exploration); the committed notebook
  contains the full logs and plots of one complete 100,000-episode run.
- Re-running the training cells takes minutes to hours; the committed outputs
  let you read all results without re-running.
